## Combined SVGF A/B (rule 9): the three SVGF flips together vs the previous default

q25, q26 and q31 were each measured alone (DISTANCE-LONG §6, T3 §6, SVGF-FOLLOWUPS §3.3). Here they run together, on the
old code with explicit options (`svgf-auto@f16Rounding=nearest@antiLagChroma=1@normalTest=soft`; occlusion
`occlusion-svgf-auto@f16Rounding=nearest@normalTest=soft`), against the old default in the same page / on the same inputs.
The new arm is byte-identical to the new default (checked on bistro-orbit, below).
