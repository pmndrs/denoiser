## What exists today

`denoiser/three` currently exports three small helpers
(`packages/denoiser-three/src/shared/three.ts`). They need `three` r185 or newer
(an optional peer dependency) and a `WebGPURenderer` that has been initialized
with `await renderer.init()`.

| export | purpose |
|---|---|
| `getDevice(renderer)` | the `GPUDevice` owned by an initialized `WebGPURenderer`; throws if the renderer is not initialized or not backed by WebGPU |
| `getGPUTexture(renderer, texture)` | the raw `GPUTexture` behind a three texture; it must already exist on the GPU (rendered to, or passed through `renderer.initTexture()`) |
| `CameraHistory` | builds the [`FrameCamera`](./realtime-temporal-denoising#guides-and-camera) a temporal denoiser needs from a three camera and keeps the previous frame's matrices |

```ts
import { getDevice, getGPUTexture, CameraHistory } from 'denoiser/three';
import { FfxShadowDenoiser } from 'denoiser/ffx';

await renderer.init();
const device = getDevice(renderer);
const shadows = new FfxShadowDenoiser(device);
shadows.configure({ width, height });

const history = new CameraHistory();

// per frame, after the camera has moved:
const camera = history.update(threeCamera, { unjitteredProjection, jitter });
// then: shadows.dispatch(inputs, guides, camera)
```

Call `CameraHistory.update()` once per frame, after the camera has moved and
before `dispatch()`. `reset()` stops reprojecting from the old pose after a cut;
the denoiser's own `resetHistory()` handles its history.

For the existing zero-copy single-image path with three.js render targets, see
[three.js render targets in / out](./three-js-render-targets).
