`Denoiser` is a single-image denoiser: async, whole-frame, no history. That is
right for stills and progressive refinement. A real-time renderer needs a
per-frame loop that reprojects the previous result with motion vectors,
accumulates, and handles disocclusion and camera cuts. That is the job of
**`TemporalDenoiser`**, exported from `denoiser` and `denoiser/core`. The first
implementations are AMD's FidelityFX shadow and reflection denoisers, ported to
WGSL and exposed as `denoiser/ffx`.

> [!NOTE]
> The OIDN RT weights are single-frame models. Running them per frame would
> flicker, so they are not wired into this API. The interface is
> source-agnostic, so a neural temporal model (OIDN 3, once upstream ships it)
> can implement it later.

## The API

```ts
interface TemporalDenoiser<Inputs extends object = object> {
  readonly name: string;                 // e.g. 'ffx-shadows'
  readonly device: GPUDevice;
  configure({ width, height }): void;    // (re)allocate; drops history
  dispatch(inputs: Inputs, guides: FrameGuides, camera: FrameCamera): GPUTexture;
  resetHistory(): void;                  // camera cut
  readonly gpuTimings?: ReadonlyMap<string, number>;
  dispose(): void;                       // never destroys the device
}
```

### Frame contract

- **Synchronous, encode-and-submit.** Call `dispatch()` **after** the frame's
  inputs have been submitted. It records its passes and submits them on
  `device.queue` with no awaits and no readback, so anything you submit afterwards
  sees the result. This is why it fits inside a render loop (the single-image
  engine has to await).
- **The returned texture is owned by the denoiser.** It is valid until the next
  `dispatch()`, `configure()` or `dispose()`. Sample or copy it before then.
- `configure()` allocates for a size and drops history. Call it before the first
  dispatch and again on resize.
- `resetHistory()` drops all history on the next dispatch. Call it on camera cuts,
  teleports and scene switches.
- `dispose()` releases the denoiser's GPU resources and never destroys the device.
- `gpuTimings` holds per-pass GPU times in milliseconds when the device supports
  `timestamp-query`; `total` is the sum of the passes.

### Guides and camera

Every temporal filter needs the same reprojection inputs, so they are shared.
All textures are the same size as the signal.

```ts
interface FrameGuides {
  depth: GPUTexture;       // hardware depth (depth32float / depth24plus) or r32float
  normal: GPUTexture;      // world-space unit normals in [-1, 1] (rgba16float / rgba8snorm)
  motion: GPUTexture;      // NDC delta, current - previous (rg16float)
  roughness?: GPUTexture;  // perceptual roughness [0, 1] (r8unorm / r16float), specular signals
  albedo?: GPUTexture;     // surface albedo [0, 1]
}

interface FrameCamera {
  view: Mat4;              // column-major 4x4, as three.js Matrix4.elements
  projection: Mat4;        // WITHOUT jitter
  prevView: Mat4;
  prevProjection: Mat4;
  jitter?: readonly [number, number]; // sub-pixel jitter of this frame, in pixels (default [0, 0])
  near: number;
  far: number;
  position?: readonly [number, number, number]; // world-space camera position
  reversedDepth?: boolean; // reversed-Z (1 = near), default false
}
```

The conventions match [`@pmndrs/upscaler`](https://github.com/pmndrs/upscaler)
(FSR3), so a chain such as render, denoise, upscale runs on one device with one
set of guides:

- **Motion** is the NDC delta, current minus previous, which is three.js'
  `velocity` node.
- **Projection** is the unjittered projection matrix (the upscaler's
  `unjitteredProjectionMatrix`), plus the jitter separately.
- Matrices are column-major.
- The API is `configure` / `dispatch` / `resetHistory` / `dispose`.

### Signal inputs

Filters are signal-specific because one filter cannot serve them all: shadows
need penumbra-aware kernels, reflections need roughness-driven lobes and
hit-distance reprojection, GI needs wide kernels and long history.

| type | fields | used by |
|---|---|---|
| `ShadowInputs` | `visibility` (1-spp, [0, 1], 1 = lit), optional `hitDistance` | `FfxShadowDenoiser` |
| `SpecularInputs` | `radiance` (linear HDR, rgba16float), `hitDistance` (r16float, 0 = miss) | `FfxReflectionDenoiser` |
| `DiffuseInputs` | `radiance`, optional `hitDistance` | none yet |
| `BeautyInputs` | `color`, optional `albedo` / `normal`, `hdr` | none yet (reserved for neural temporal models) |

## FidelityFX denoisers (`denoiser/ffx`)

`denoiser/ffx` is a WGSL port of the AMD FidelityFX Denoiser from FidelityFX SDK
**v1.1.4** (MIT; AMD's notice is kept in every ported file). The constructors take
a `GPUDevice` and options. Only core WebGPU is required (core storage formats, at
most four storage textures per stage, so default limits are enough);
`timestamp-query` is used for `gpuTimings` when present. There are no runtime
dependencies.

### Shadows

```ts
import { FfxShadowDenoiser } from 'denoiser/ffx';

const shadows = new FfxShadowDenoiser(device);
shadows.configure({ width, height });

// every frame, after the frame's inputs are submitted:
if (cameraCut) shadows.resetHistory();
const mask = shadows.dispatch(
  { visibility },                 // r32float / r16float / r8unorm, 1 = lit
  { depth, normal, motion },      // FrameGuides
  { view, projection, prevView, prevProjection, near, far },
);
// `mask` (rgba16float, .r = denoised visibility) is valid until the next dispatch.
```

Input requirements:

- `visibility` is one ray or shadow-map sample per pixel. FFX is a **binary**
  one-ray denoiser, so fractional visibility (PCF and the like) is thresholded:
  values at or above `visibilityThreshold` (default 0.5) count as lit.
- `hitDistance` is accepted but unused. FFX shadows do not use blocker distance.
- Zero-length (sky) normals are guarded against, so they do not turn into NaN
  filter weights.

Options (`FfxShadowDenoiserOptions`): `depthSimilaritySigma` (default 1),
`visibilityThreshold` (default 0.5), `timestamps` (default true).

### Reflections

```ts
import { FfxReflectionDenoiser } from 'denoiser/ffx';

const reflections = new FfxReflectionDenoiser(device);
reflections.configure({ width, height });

const out = reflections.dispatch(
  { radiance, hitDistance },             // rgba16float linear HDR, r16float (0 = miss)
  { depth, normal, motion, roughness },  // roughness is required
  camera,                                // FrameCamera, including `position` and `far`
);
```

Input requirements:

- `guides.roughness` is **required**. It is perceptual roughness by default; set
  `roughnessIsPerceptual: false` if yours is linear.
- `hitDistance` of 0 (or less) means a miss; misses use `missDistance`
  (default `camera.far`).
- Radiance must be **finite and greater than zero wherever there is a
  reflection**. The resolve pass treats `r+g+b < 1e-4` as "no reflection" and
  outputs 0, and a single NaN wipes a 7x7 prefilter footprint.
- Every pixel is assumed to have been traced. The default `roughnessThreshold` of
  1 denoises all pixels.

Options (`FfxReflectionDenoiserOptions`): `temporalStabilityFactor` (default 0.7;
higher is more stable and more ghosting), `roughnessThreshold` (default 1),
`roughnessIsPerceptual` (default true), `missDistance`, `currentFrameStatistics`
(default true), `timestamps` (default true).

`currentFrameStatistics` fixes a one-frame-off ping-pong in the v1.1.4 host code
that blends zeroed history at disocclusions (dark speckles) and outputs a
near-black first frame after a reset. `false` reproduces the SDK exactly.
`resetHistory()` also drops the geometry history, which FFX's own reset does not.

### How the guides map onto FFX

| FFX concept | what you pass |
|---|---|
| motion vector scale (-0.5, 0.5) | motion as an NDC delta, current minus previous |
| normals unpack mul/add 1 / 0 | world normals already in [-1, 1] |
| inverted depth | `camera.reversedDepth` |
| jitter | ignored by default: positions are reconstructed from the unjittered projection. `compensateJitter: true` reprojects with `jitter - prevJitter`, but it never helped (see [With the upscaler](#with-the-upscaler)) |

### Measured results

A test bed (`examples/ffx-denoiser`) renders an analytic scene with an area light,
spheres, boxes and a roughness-banded plane, with a scripted 120-frame camera path
(orbit and dolly, a hard cut at frame 60 that calls `resetHistory()`, then a
lateral truck). Everything is compared against a 256-spp reference of the same
estimator at 1920x1080 on an Apple M5 Pro (Chrome 154).

**Shadows**

| | PSNR all | PSNR penumbra | flicker | bias (penumbra) |
|---|---|---|---|---|
| noisy 1 spp | 17.63 dB | 7.80 dB | 0.0393 | n/a |
| FFX shadows, spatial only | 34.07 dB | 24.55 dB | 0.0055 | -0.030 |
| **FFX shadows** | **34.24 dB** | **25.06 dB** | **0.0029** | -0.042 |

The temporal part halves flicker and adds about 0.5 dB in the penumbrae. With a
static camera, penumbra PSNR peaks after about 10 frames (25.1 dB) and drifts down
about 1 dB, because FFX's history is the output of filter pass 0 and the spatial
blur compounds over frames (slightly softened contact shadows).

**Reflections** (after a Reinhard tonemap)

| | PSNR | flicker | bias |
|---|---|---|---|
| noisy 1 spp | 18.05 dB | 0.0845 | n/a |
| FFX reflections, spatial only | 24.50 dB | 0.0157 | -0.039 |
| FFX reflections, SDK-exact (`currentFrameStatistics: false`) | 22.17 dB | 0.0174 | -0.050 |
| **FFX reflections (default)** | **23.46 dB** | **0.0080** | -0.040 |

An honest reading: in this scene FFX reflections halves flicker against its own
spatial-only result, at the price of about 1 dB PSNR under fast camera motion
(ghosting on glossy surfaces, conservative disocclusion rejection), and the result
is biased dark by about 0.04 (tonemapped). That bias is by design: the prefilter and
resolve both pull toward a luminance-weighted 8x8 average that suppresses
fireflies, and loosening `temporalStabilityFactor` does not change it. On the first
frame after a reset the default scores 19.8 dB and the cut frame 30.4 dB, against
4.8 dB and 10.1 dB for SDK-exact.

**GPU cost, 1080p** (timestamp queries, median of 100, idle GPU, Apple M5 Pro):

| denoiser | GPU time |
|---|---|
| shadows | **0.49 ms** |
| reflections | **1.66 ms** |

Not optimized yet: there are no subgroup paths (wave intrinsics are emulated in
workgroup memory), and reflection reproject and resolve each build a 9x9
neighbourhood per pixel from workgroup memory. FFX's SSSR tile classifier is part
of SSSR, not the denoiser, so it is not in this port.

## With the upscaler

`examples/ffx-upscale-chain` runs `render → denoise → @pmndrs/upscaler` on one `GPUDevice`: a jittered
640×360 ray-traced render (1 shadow or reflection ray per pixel), the FFX denoiser, a compose pass
(`colour = ambient + lit × shadow + K × reflection`) and temporal upscaling to 1280×720. Each frame is
scored against a 4×4-supersampled native render. Scores are PSNR (tonemapped) over the pixels where the
signal matters: shadow penumbrae (5–12% of the frame) or reflecting surfaces (70–83%), steady-state frames
only. `noisy` is the raw 1-spp signal straight into the upscaler, `oracle` a converged signal at the
jittered sample position.

| scenario | shadows: noisy → denoised (oracle) | reflections: noisy → denoised (oracle) |
|---|---|---|
| static camera | 39.9 → **41.5** (42.6) | **29.1** ← 22.5 (34.8) |
| camera path | 37.1 → **37.7** (38.2) | **28.4** ← 27.3 (33.2) |
| camera path ×3 | 34.1 → **36.9** (37.3) | 29.9 → **30.7** (35.2) |
| orbiting spheres, static camera | 34.8 → **35.2** (35.7) | **26.9** ← 21.8 (31.6) |
| camera ×2 + spheres ×2 | 33.3 → **35.1** (35.6) | 31.5 → **32.6** (34.9) |
| first frames after a history reset | 31.7 → **35.9** (36.3) | 19.0 → **21.8** (32.1) |

- **Shadows:** the denoiser helps everywhere, and the gain grows with motion, up to +2.8 dB with a fast
  camera, because the upscaler's own accumulation can't average the noise there. After a camera cut it is
  worth about 4 dB.
- **Reflections:** it only pays once the camera or objects move fast. In a still view the upscaler
  accumulating the raw 1-spp signal beats the denoiser by 5–7 dB. The denoised result is smooth but biased
  dark (mean error −0.039 vs −0.014 undenoised, tonemapped) and visibly hazier, a bias accumulation
  cannot average away. `temporalStabilityFactor` and `currentFrameStatistics` do not change it. It still wins
  after resets (+2.5 to +6.8 dB). Practical rule: bypass or blend it down while the view is converged.
- **Jitter:** leave it out. `compensateJitter` (reproject with `jitter - prevJitter`) was equal to
  ignoring it, or up to 0.2 dB worse, in every scenario, and so was a variant that treats the history as
  centred at the pixel centre. Compensating forces a fractional history fetch every frame, and the repeated
  bilinear resampling blurs more than the sub-pixel offset it fixes. Running the shadow denoiser on a fully
  unjittered lattice gained nothing either. Feed it the jittered G-buffer as is.
- **Scope:** one analytic scene, one run per configuration (fixed seeds, differences under ~0.2 dB are
  noise-level), moving objects are three orbiting spheres. The raw-WebGPU chain does not reproduce the
  residual flicker the TSL nodes show with jitter (flicker equals the oracle's when static).

Reproduce: `yarn workspace ffx-upscale-chain dev`, then
`node examples/ffx-denoiser/run-headless.mjs "mode=eval&sig=shadows&cond=ignore&speed=3"` with
`BASE=http://127.0.0.1:5211/` (`UPSCALER_SRC=<checkout>/src/index.ts` tests unreleased upscaler code).

## Using it with raw WebGPU

The temporal API is engine-agnostic. You need a `GPUDevice`, the signal and the
guides as `GPUTexture`s in the formats above, and the camera matrices.

```ts
import { FfxShadowDenoiser, type FrameCamera } from 'denoiser/ffx';

const adapter = await navigator.gpu.requestAdapter();
const device = await adapter!.requestDevice({
  requiredFeatures: adapter!.features.has('timestamp-query') ? ['timestamp-query'] : [],
});

const shadows = new FfxShadowDenoiser(device);
shadows.configure({ width: canvas.width, height: canvas.height });

function frame(camera: FrameCamera, cut: boolean) {
  renderGBufferAndShadowRays(device);   // your pass: writes depth, normal, motion, visibility
  if (cut) shadows.resetHistory();
  const mask = shadows.dispatch({ visibility }, { depth, normal, motion }, camera);
  compositePass(device, mask);          // your pass: sample `mask.r` this frame
}
```

Sizes passed to `configure()` must match the signal and guides. Resize by calling
`configure()` again, which drops history.

## three.js and TSL

`denoiser/three` wraps a `TemporalDenoiser` as a TSL node the way
`@pmndrs/upscaler`'s `UpscalerNode` wraps the upscaler: `ffxShadows()`,
`ffxReflections()` and the generic `temporalDenoise()`. The nodes only advance inside
`renderer.setAnimationLoop`, and with FSR3 jitter enabled they currently show much
higher residual flicker (open issue). See [three.js & TSL](./three-and-tsl).
