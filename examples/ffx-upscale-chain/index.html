FFX shadow / reflection denoiser → @pmndrs/upscaler

One ray per pixel, denoised, composed with the colour and temporally upscaled 2× — three packages, one GPUDevice. Compare against a supersampled native render of the same frame.

What this shows

  • The scene is ray traced analytically at 640×360 with sub-pixel jitter. Every frame each pixel gets one shadow ray (or one glossy reflection ray), so the raw signal is noisy.
  • The FidelityFX denoiser cleans that signal, the result is composed into the colour, and FSR-style temporal upscaling (@pmndrs/upscaler) reconstructs 1280×720.
  • Jitter is deliberately not given to the denoiser. Measured here: compensating for it blurs the history (bilinear resampling each frame) and never beats leaving it out; see docs/specs/temporal.md.
