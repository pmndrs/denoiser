denoiser — WebGPU denoising for the web

Path-traced frames are denoised with Intel Open Image Denoise (OIDN) networks, matching native OIDN output, on interchangeable runtimes (hand-written WGSL, WebNN, ONNX Runtime; AutoRuntime picks one). Raster and hybrid pipelines get real-time temporal denoisers (AMD FidelityFX shadows and reflections, ported to WGSL). Everything shares one GPUDevice with your renderer, including three.js WebGPURenderer / TSL nodes. No native code, no server round-trip. These demos need a WebGPU browser (Chrome/Edge 113+, Safari 26+) and have been validated on Apple GPUs only so far.

Run the examples locally

git clone https://github.com/pmndrs/denoiser
cd denoiser
yarn install
yarn build:lib
yarn examples          # http://localhost:5160/

One dev server for everything: this page at / and every example at /<name>/, the same paths as this site. The tools & tests above only run there. yarn examples --list prints them; yarn examples <name> starts one example on its own.

Enable WebNN in Chrome

The WebNN runtime (and AutoRuntime's fp16 WebNN path) needs WebNN, which Chrome still ships behind a flag. Without it the examples fall back to WGSL and the WebNN button is greyed out.

Turn on chrome://flags/#web-machine-learning-neural-network ("WebNN API") and relaunch, or start Chrome with:

--enable-features=WebMachineLearningNeuralNetwork
