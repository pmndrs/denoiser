The corner of the realtime shadows page with a stained-glass panel (amber and blue stripes in a dark frame) between the area light and the floor. Each pixel traces one shadow ray: opaque visibility and occluder distance against the scene meshes, and the panel's transmittance T along the same ray. Left of the divider: realtimeShadows() on v x lum(T) (right brightness, no colour). Right: realtimeShadows() with translucency: T, which keeps the opaque visibility and a conditional transmittance apart and returns the coloured shadow.

How it works

  • The renderer multiplies the transmittance of every translucent layer the shadow ray crosses (order doesn't matter) and reports the nearest one's distance; a ray stopped by an opaque surface keeps visibility 0 (its T is ignored).
  • The denoiser keeps filtering the opaque visibility exactly as without glass, and accumulates T only over samples that reached the light; the output is their product, so overlapping opaque and coloured penumbrae stay right.
  • The panel here is an analytic quad (one ray-quad test per pixel); its frame is ordinary geometry in the BVH.
  • denoiser/realtime is experimental. Numbers: docs/research/rt-denoiser/results/M8.md.
import { realtimeShadows } from 'denoiser/three';

const shadow = realtimeShadows(visibility, {
  camera, depth, velocity, normal, normalSpace: 'view', normalEncoding: 'packed',
  hitDistance: occluderDistance,               // world units, 0 = unoccluded
  light: () => ({ type: 'sphere', position: [x, y, z], radius }),
  translucency: transmittance,                 // rgb T of the ray (1 where it crossed no layer)
  translucencyHitDistance: glassDistance,      // nearest translucent layer, 0 = none
});
const lit = sceneColor.add(albedo.mul(irradiance).mul(shadow.rgb));   // shadow.visibility = opaque part
