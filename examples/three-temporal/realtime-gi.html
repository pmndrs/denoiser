Realtime GI, reflections and AO experimental

The same furnished corner, now lit only by what is traced at one ray per pixel: a diffuse bounce ray (the environment where it escapes, the area light bounced where it hits), three's stochastic SSR for reflections, and a shadow ray. realtimeDiffuseSpecular() denoises diffuse and specular in one dispatch, realtimeOcclusion() turns the diffuse ray's hit distance into AO, realtimeShadows() the shadow (all from denoiser/three, backed by denoiser/realtime). Left of the divider: what you have without them (the raw diffuse signal, ffxReflections() for SSR).

Notes

  • The diffuse signal is demodulated (not multiplied by albedo), as DiffuseSpecularDenoiser expects; the composite multiplies by albedo afterwards.
  • Each denoiser runs with its class defaults; the algorithm is an option (denoiser: { filter: 'svgf' | 'recurrent' }).
  • The reference accumulates independent samples while the camera holds still (diffuse: 4 rays/frame; specular: the SSR itself, so it shares SSR's own misses).
  • denoiser/realtime is experimental: defaults and API may change. Numbers: docs/research/rt-denoiser/results/M6-real-scene.md.
import { realtimeDiffuseSpecular, realtimeOcclusion } from 'denoiser/three';

const guides = { camera, depth, velocity, normal, normalSpace: 'view', normalEncoding: 'packed' };
const gi = realtimeDiffuseSpecular(
  { diffuse: { radiance: diffuseRay, hitDistance }, specular: { radiance: ssrNode /* ray length in .a */ } },
  { ...guides, roughness },
);
const ao = realtimeOcclusion(hitDistance, guides);
const lit = albedo.mul(gi.diffuse.rgb.add(direct)).add(gi.specular.rgb);
