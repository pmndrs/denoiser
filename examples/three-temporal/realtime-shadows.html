What is different

  • FFX's shadow denoiser treats each ray as lit or shadowed and filters a fixed footprint.
  • ShadowDenoiser keeps fractional visibility, accumulates raw visibility only, and sizes its spatial kernel per pixel from the penumbra width (occluder distance and light size) blended with a noise estimate.
  • Light samples are spatiotemporal blue noise here, as its renderer contract asks (?sampler=white gives both denoisers the white noise of the shadows page).
  • denoiser/realtime is experimental: defaults and API may change. Numbers for this scene: docs/research/rt-denoiser/results/M6-real-scene.md.
import { ffxShadows, realtimeShadows } from 'denoiser/three';

const guides = { camera, depth, velocity, normal, normalSpace: 'view', normalEncoding: 'packed' };
const ffx = ffxShadows(visibility, guides);
const ours = realtimeShadows(visibility, {
  ...guides,
  hitDistance: occluderDistance,                       // world units, 0 = unoccluded
  light: () => ({ type: 'sphere', position: [x, y, z], radius }),
});
const lit = sceneColor.add(albedo.mul(irradiance).mul(ours.r));
