denoiser vs oidn-web

One path-traced frame, two implementations of Intel's OIDN networks: this library and oidn-web, the one three-gpu-pathtracer's OIDNDenoiser uses (plus its older TensorFlow.js build). Same weights, same inputs, same GPU device, run one after the other. Drag the divider; orbit with the mouse. 


        

          
What we measured

          
oidn-web is no longer the TensorFlow.js port it started as. 0.4 (August 2026) replaced TF.js with
            hand-written WGSL and an experimental WebNN engine, and 0.5 (October 2026) moved its fp16 convolutions to
            implicit GEMM. three-gpu-pathtracer's OIDNDenoiser doesn't bundle it: you pass in
            initUNetFromURL, so your app picks the version. The tracer's own demo pins ^0.4.0
            (0.4.x only) and runs the default tiling, the "default tiles" column below.
